# API Data Extraction Assignment

## Overview
This assignment demonstrates a basic REST API data extraction workflow for the Bluestock FinTech Internship – Week 2.

## API Used
- API: DummyJSON Products API
- Method: GET
- Endpoint: https://dummyjson.com/products?limit=10&select=id,title,category,price,rating,stock

## Process
1. Sent a GET request to the public API using Postman.
2. Inspected the JSON response.
3. Extracted the product data from the `products` array.
4. Converted the JSON data into a CSV file for analysis.

## Fields Extracted
- ID
- Title
- Category
- Price
- Rating
- Stock

## Output
The extracted data is available in the accompanying CSV file:
`Bluestock_Week2_API_Products.csv`
