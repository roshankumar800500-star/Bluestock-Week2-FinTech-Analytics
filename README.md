# Bluestock FinTech Internship — Week 2

This repository contains the practical assignments completed as part of the **Bluestock FinTech Data Analyst Internship – Week 2 Prerequisite**.

## Objective

The purpose of this week is to understand the financial domain and basic software development concepts relevant to Data Analysts working in a FinTech environment.

## Week 2 Deliverables

### 1. Stock Market Fundamentals

A one-page summary covering:

* Stock Market
* NSE & BSE
* Nifty & Sensex
* IPO & SME IPO
* Market Capitalization
* P/E Ratio
* P/B Ratio
* EPS
* Dividend
* Bonus & Stock Split
* Trading Volume
* Financial Statements

### 2. Financial Statement Analysis

Financial statement analysis of **Tata Consultancy Services Limited (TCS)** covering:

* Profit & Loss Statement
* Balance Sheet
* Cash Flow Statement
* Financial Ratios
* Analyst Interpretation

### 3. REST API & JSON

A practical API data extraction assignment using:

* REST API
* GET request
* JSON response
* Postman
* JSON to CSV conversion

The API output is available in the `API_Assignment` folder.

### 4. Git & GitHub

This repository demonstrates:

* Repository creation
* File upload
* Commits
* Version history
* Organized assignment structure
